Pilih file ekspor data TikTok-mu. Daftar video Favorit tampil per halaman, lengkap dengan tanggal disimpan, jadi kamu tidak perlu menggulir ribuan video di TikTok.

Tidak ada yang diunggah. Tidak diminta password, cookie, atau login TikTok.

Isi file ekspor

File ekspor berisi daftar tautan (dan tanggal, bila ada), bukan salinan videonya. Video yang sudah dihapus atau dijadikan privat tidak bisa dipulihkan; tautannya akan gagal dibuka di TikTok.

File-mu tetap di perangkat ini

Pemrosesan terjadi di browser ini. Tidak ada unggahan, analitik, atau pelacak. TikTok baru dihubungi saat kamu menekan Buka di TikTok.

Belum punya file? Coba dulu dengan data fiktif

Cara meminta data dari TikTok
  1. Di aplikasi TikTok, buka Profil, lalu menu di pojok kanan atas, lalu Pengaturan dan privasi. Cari Unduh data Anda: biasanya di bawah Akun, atau di bawah Privasi dan keamanan lalu Personalisasi dan data. Nama dan letak menu berbeda di tiap versi aplikasi.
  2. Pilih format JSON. Jika kamu tidak yakin kategori mana yang memuat Favorit, pilih Semua data; aplikasi ini hanya membaca bagian yang relevan. Jika file terlalu besar untuk HP, coba kategori yang lebih sedikit.
  3. Ajukan permintaan dan tunggu sampai siap (dari seketika sampai beberapa hari). Tautan unduhan hanya berlaku beberapa hari, jadi unduh begitu siap.
  4. Kembali ke sini dan pilih file hasil unduhan. File .zip tidak perlu diekstrak.
Batasan yang perlu kamu tahu
  • Aplikasi ini hanya membaca file yang kamu pilih. Ia tidak mengambil Favorit langsung dari akun TikTok.
  • Tidak ada thumbnail, judul, atau nama akun, kecuali memang tertulis di file (biasanya hanya tautan dan tanggal).
  • Tanggal ditampilkan persis seperti tertulis di file; zona waktu tidak diubah.
  • Bagian Favorit, Disukai, dan Riwayat tontonan tidak dicampur kecuali kamu sendiri yang memilih.

    Privasi dan keamanan
    
  
    File-mu
    
  
    Dibaca dan diurai di browser ini (dalam Web Worker). Tidak diunggah ke server mana pun. Halaman ini memasang aturan keamanan (CSP) yang melarang koneksi keluar, jadi skripnya tidak bisa mengirim data.
    
  
    Yang disimpan di perangkat
    
  
    Pilihan tampilan, penanda, dan posisi terakhir (localStorage). Penanda berisi ID atau alamat video yang kamu tandai. Daftar lengkap hanya disimpan jika kamu menyalakan opsinya (IndexedDB). File mentah tidak pernah disimpan.
    
  
    Kapan TikTok dihubungi
    
  
    Hanya saat kamu menekan Buka di TikTok. Tautan dibuka dengan noopener dan noreferrer, dan halaman ini tidak mengirim referrer. Hanya tautan HTTPS ke domain TikTok yang sah yang bisa dibuka.
    
  
    Yang tidak ada
    
  
    Analitik, pelacak, cookie, login, dan sumber daya dari CDN saat berjalan.
    
  
    Tempat halaman ini dihosting
    
  
    Penyedia hosting bisa melihat bahwa halaman ini dibuka, tetapi tidak isi file-mu karena file tidak pernah dikirim.
